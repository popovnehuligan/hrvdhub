Wishlist setup

Connect the wishlist to Google, so the whole team shares one list. About 5 minutes, copy, paste and click.

At the end the bot gets this picture, its description and the «Вишлист» button by itself.

  1. Make a new Google Sheet

    Be signed in to Google as horovod.info@gmail.com, then open:

    Open a new sheet

    Name it HOROVOD · Вишлист (click “Untitled spreadsheet” at the top left).

  2. Open its script editor

    In the sheet’s menu: Extensions → Apps Script. A new tab opens with a little code in it.

  3. Paste the wishlist script

    Paste the wishlist bot’s key here (the one you gave Claude at the start):

    The key stays on this computer: it only goes into the script you copy.

    Then in the Apps Script tab select everything (Ctrl+A / ⌘A), paste (Ctrl+V / ⌘V) and press the save icon 💾.

  4. Put the bot in the group

    In Telegram, open the HOROVOD group → Add members → find the wishlist bot → add it. It doesn’t need to be an admin.

    Then, inside the Wishlist topic, send /start@ followed by the bot’s username, for example /start@horovod_wishlist_bot. That’s how the bot learns to post in that topic.

  5. Run setup

    Back in Apps Script, at the top pick setup in the dropdown and press Run.

    Google asks for permission: Review permissions → choose horovod.info@gmail.com → Advanced → Go to … (unsafe) → Allow.

    “Unsafe” only means Google hasn’t reviewed this private script; the bar bot’s script got the same warning. At the bottom a log shows every step with ✓. If a line has ✗, it says what to do.

  6. Publish the script

    Top right: Deploy → New deployment. Click the gear next to “Select type” → Web app.

    • Execute as: Me
    • Who has access: Anyone

    Press Deploy, copy the Web app URL (it ends with /exec) and send it to Claude. Claude connects the app to it, and the «Вишлист» button in the bot opens the real, shared wishlist.
