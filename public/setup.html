Wishlist setup

Connect the wishlist to Google, so the whole team shares one list. About 5 minutes, copy and paste only.

  1. Make a new Google Sheet

    Be signed in to Google as horovod.info@gmail.com, then open:

    Open a new sheet

    Name it HOROVOD · Вишлист (click “Untitled spreadsheet” at the top left).

  2. Open its script editor

    In the sheet’s menu: Extensions → Apps Script. A new tab opens with a little code in it.

  3. Paste the wishlist script

    Press this button, then in the Apps Script tab select everything (Ctrl+A / ⌘A), paste (Ctrl+V / ⌘V) and press the save icon 💾.

    Name the project “HOROVOD Вишлист” if it asks.

  4. Add the bot key

    On the left, click the gear ⚙ Project Settings, scroll down to Script Properties → Add script property, and add two:

    • BOT_TOKEN — the wishlist bot’s key (the one you gave Claude at the start)
    • APP_URL — https://popovnehuligan.github.io/hrvdhub/

    Press Save script properties.

  5. Put the bot in the group

    In Telegram, add the wishlist bot to the HOROVOD group and write any message there (for example “hi”).

  6. Run setup once

    Back in Apps Script, click < > Editor on the left. At the top, pick setup in the dropdown and press Run.

    Google asks for permission: Review permissions → choose horovod.info@gmail.com → Advanced → Go to HOROVOD Вишлист (unsafe) → Allow.

    “Unsafe” only means Google hasn’t reviewed this private script. The bar bot’s script got the same warning. At the bottom you’ll see what it did, e.g. “Группа найдена”.

  7. Publish the script

    Top right: Deploy → New deployment. Click the gear next to “Select type” → Web app.

    • Execute as: Me
    • Who has access: Anyone

    Press Deploy and copy the Web app URL (it ends with /exec).

  8. Send that URL to Claude

    Claude connects the app to it and publishes. Then the «Вишлист» button in the bot opens the real, shared wishlist.
