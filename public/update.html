Последнее ручное обновление

Пара минут. После этого скрипт в Google будет обновляться сам, и Claude сможет выкладывать изменения без вас.

  1. Вставьте скрипт

    В Apps Script вишлиста откройте файл Code.gs, выделите всё (Ctrl+A / ⌘A), вставьте (Ctrl+V / ⌘V) и нажмите 💾.

    Ключ бота вставлять не нужно: он уже сохранён в скрипте. Файл appsscript.json трогать не нужно.

  2. Запустите setup

    Вверху выберите функцию setup и нажмите Run. В логе внизу должна быть строка ✓ Автообновление: свежий код с GitHub.

  3. Опубликуйте

    Справа вверху: Deploy → Manage deployments → карандаш ✏️ → в поле Version выберите New version → Deploy.

    Это в последний раз: дальше новые версии включаются сами.
