Последнее ручное обновление

Минут пять. После этого скрипт в Google будет обновляться сам, и Claude сможет выкладывать изменения без вас.

  1. Разрешите скриптам обновляться

    Войдите как horovod.info@gmail.com, откройте страницу ниже и включите переключатель Google Apps Script API.

    Открыть настройки

  2. Покажите файл настроек проекта

    В Apps Script вишлиста слева нажмите ⚙️ Project Settings и поставьте галочку Show "appsscript.json" manifest file in editor.

  3. Вставьте скрипт

    Слева нажмите <> Editor, откройте файл Code.gs, выделите всё (Ctrl+A / ⌘A), вставьте (Ctrl+V / ⌘V) и нажмите 💾.

    Ключ бота вставлять не нужно: он уже сохранён в скрипте.

  4. Вставьте настройки проекта

    Откройте файл appsscript.json, выделите всё, вставьте и нажмите 💾.

  5. Запустите setup

    Вверху выберите функцию setup и нажмите Run. Google попросит новые разрешения: Review permissions → horovod.info@gmail.com → Advanced → Go to … (unsafe) → Allow.

    Внизу в логе должна быть строка ✓ Автообновление включено. Нажимать Deploy не нужно: setup сам выложит новую версию.

    Если в строке ✗, там написано, что сделать. Или пришлите скриншот Claude.
